# AI-GENERATED-VS-STUDENT-JOURNALISM
MAT results and AI-generated journalistic texts accompanying a multidimensional register comparison of student journalism and outputs from ChatGPT, Microsoft Copilot, and Google Gemini.

This repository accompanies the study “AI-generated vs student journalism in higher education: A multidimensional register analysis for AI literacy and writing pedagogy.”

The study examines how journalistic texts generated by ChatGPT, Microsoft Copilot, and Google Gemini approximate the register profiles of university-level student-authored news and feature articles. It uses Biber’s multidimensional framework, as implemented through the Multidimensional Analysis Tagger (MAT), to compare six dimensions of register variation and examine agreement in MAT-assigned text-type classifications.

This repository contains the MAT results and AI-generated texts used in the study. The original student-authored articles are not included in the public deposit.
